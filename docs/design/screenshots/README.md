# Screenshots

Only the captures cited from the documents in `docs/design/` are kept here, downscaled to
1400px wide. The full capture set (85 images at 2–3× DPR, ~66 MB) was working material for
the audit and is deliberately not in git.

Everything here was captured with headless Chrome over CDP against either the local dev
server or `https://www.taash.tax/`. Anything measured from these images (contrast ratios,
pixel sampling) was measured on the full-resolution originals, not these copies.
